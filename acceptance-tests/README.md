# Acceptance evidence

Each implementation phase will have its own folder containing a coverage checklist, reproducible commands, results and relevant screenshots or machine-readable reports. Never store passwords, session cookies, API keys, database URLs or private provider responses here.

A passing frontend build alone does not establish functional acceptance. Report local tests separately from production deployment and production smoke tests. Mark skipped, blocked and failed checks explicitly. Commit a phase only after its required local checks pass; do not claim a Render deployment without observing its outcome.
